## 当前进度
当前入口为主菜单 → 部落村落 → 右侧道路出征选择 → 三波普通战斗 → 野猪王。波间支持构筑调整与两种撤离节奏；回城需走进传送门。

另有林地外围、动作试验场、手动剑、野狼、装甲目标、物品表、背包/掉落、安全点存档及只读店铺。当前玩家使用猎人占位图；历史 LPC 协议保留。

当前 Build 仍只有旧样例；装备武器自动攻击、组件实例、正式构筑 UI/预设、随机掉落和新增地图依新路线推进。玩家攻击动画不再作为前置。合作/联网 P7 与 2.2 继续冻结。

# TribeHunt

原始部落题材动作远征游戏（Godot 4.7.2；当前可运行内容包含单人战斗与最小构筑原型）。

## 快速开始
1. 用 Godot 4.7.2 打开本目录的 `project.godot`
2. 按 F5 运行
3. WASD / 方向键移动

## 当前进度
当前入口为主菜单 → 部落村落 → 右侧道路出征选择 → 三波普通战斗 → 野猪王。波间支持构筑调整与两种撤离节奏；回城需走进传送门。

2026-10-18 已统一单人武器配置、目标/命中检查，修复石弹重复伤害与结束后战斗继续的问题，并接入角色动画/外观层基础。完整分层服装与装备 UI 尚未完成。详见 [参考项目接入说明](docs/参考项目接入说明.md)。

P5 手动攻击对照仍暂缓，瞄准方式未定；合作/联网 P7 与 2.2 多设备测试仍冻结。当前构筑只含两个临时样例模块，不包含奖励、成长存档、元素或联机同步。

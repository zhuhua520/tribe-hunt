# TribeHunt 项目方案

## 一句话玩法
原始部落战士携带一件近战与一件远程武器，在封闭场地中活过数波野兽围攻。

## 设计依据
- 世界观：`../世界观v1.md`
- 玩法抽象来自对 Godot 导出包 `Brotato.pck` 的解包文本资源阅读（非 REA 反编译）。原游戏美术、名称、剧情、关卡布局与专属素材均不复制。
- 引擎：Godot 4.7.2（GDScript）

## 核心循环（目标形态）
进入场地 → 移动并自动攻击 → 活过当前波次 → 短暂准备 → 下一波 → 三波全过则胜 / 生命归零则负。

## 玩家规则（已确认）
| 项目 | 规则 |
| --- | --- |
| 主题 | 原始部落战士 |
| 武器上限 | 近战 1 + 远程 1 |
| 原型默认武器 | 木棍（近战）+ 弹弓（远程） |
| 攻击方式 | 自动攻击最近敌人，无需瞄准 |
| 第一阶段范围 | 仅战斗场景；无任务、无商店、无角色选择 |
| 胜负 | 3 波全过胜利；生命归零失败 |

## 3 个原创设计点
1. 武器上限固定为 1 近战 + 1 远程，不做多武器环绕。
2. 近战与远程同时运转，走位决定哪把武器更容易命中。
3. 第一阶段只做战斗闭环，数值与美术均可后期替换。

## 目录约定（美术独立）
```
tribe-hunt/
  assets/          # 仅美术与音频，路径稳定，可直接覆盖替换
    sprites/
      player/
      enemies/
      weapons/
      projectiles/
      ui/
    audio/sfx/
    audio/music/
    fonts/
  data/            # 数值与配置（与美术无关）
    weapons/
    waves/
    enemies/
  scenes/
    combat/
    ui/
  scripts/
    combat/
    weapons/
    enemies/
    systems/
  docs/            # 方案、进度、交接
```

### 资源原则
1. 脚本通过 `res://assets/...` 引用贴图/音频，不把颜色或尺寸当最终玩法数据。
2. 占位图与正式图使用相同文件名（如 `player.png`），替换时不改场景引用。
3. 玩法数值放 `data/` 或脚本 `@export`，不进 `assets/`。

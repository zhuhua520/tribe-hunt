# TribeHunt 项目概览

## 项目定位

原始部落题材的俯视角 2D 动作远征游戏，目标支持单人、本地合作和在线合作。玩法以移动、攻击、武器与子模块构筑、波次间撤离决策为主；不以主动技能系统增加核心操作负担。

## 当前设计依据

- [当前完整设计方案](../部落远征-完整设计方案-v2.md)
- [Godot 开发规范与约定](Godot开发规范与约定.md)
- 世界观：仓库上级目录的《世界观v1.md》
- 引擎：Godot 4.7.2
- 脚本：GDScript

## 当前原型状态

截至 2026-10-18，主菜单进入部落村落，从右侧道路选择出征。单人包含三波普通战斗、两个临时模块、波间调整、撤离节奏对照、回城传送门及野猪王胜负结果。武器配置与命中检查已统一；玩家/村落共用动画和外观层接口，完整换装资产及 UI 尚未完成。

手动瞄准方式仍未定，P5 对照暂缓；当前保留自动攻击。联机仍为早期独立测试场，未接单人构筑/新前摇/分层外观，P7 和 2.2 双设备验证仍冻结。奖励与成长存档未实现。具体修改与验证见 `进度.md` 和 `参考项目接入说明.md`。

## 目录概览

- assets：美术和音频资源
- data：波次等配置资源
- scenes：游戏场景
- scripts：GDScript
- docs：设计、进度和开发约定

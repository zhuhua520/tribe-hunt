# TribeHunt 项目概览

## 项目定位

原始部落题材的俯视角 2D 动作远征游戏，目标支持单人、本地合作和在线合作。玩法以移动、攻击、武器与子模块构筑、波次间撤离决策为主；不以主动技能系统增加核心操作负担。

## 当前设计依据

- [当前完整设计方案](../部落远征-完整设计方案-v2.md)
- [Godot 开发规范与约定](Godot开发规范与约定.md)
- 世界观：仓库上级目录的《世界观v1.md》
- 引擎：Godot 4.7.2
- 脚本：GDScript

## 当前原型状态

现有可运行原型包含主菜单与设置流程、玩家移动、木棍与弹弓自动攻击、三波刷怪、胜负，以及两个临时模块样例的出征选择和波间调整。它用于验证单人战斗和构筑入口。阶段 3.2 的模块和数值仍是临时测试基线。下一步已确认做单人自动攻击与手动攻击小原型再比较，自动攻击可以设为开关。2026-10-16 未采用「一个攻击键、最近有效目标」，手动选敌方式继续讨论。撤离点节奏留待原型比较，合作队伍一起行动并通过投票决定。最终保留哪种攻击操作、模块取得方式、奖励和波次结构仍未定。联机多设备测试仍冻结，构筑效果尚未接入联机。

## 目录概览

- assets：美术和音频资源
- data：波次等配置资源
- scenes：游戏场景
- scripts：GDScript
- docs：设计、进度和开发约定

详细阶段目标和确认状态以当前完整设计方案为准。

## 3. 打开与运行
1. 安装 / 使用 Godot 4.7.2
2. 导入并打开 `tribe-hunt/project.godot`
3. 主场景已设为 `res://scenes/combat/arena.tscn`
4. F5 运行；WASD / 方向键移动。三波刷怪；窗口标题与顶部 HUD 显示状态/生命；胜负后可重新开始。

## 4. 当前代码地图（步骤 1–5，最小原型已闭环）
| 路径 | 职责 |

| `scenes/combat/arena.tscn` | 主场景：场地、玩家、WaveManager、CombatHUD |

| `project.godot` | 主场景、窗口、输入动作 |

### 碰撞层约定
- 1：玩家
- 2：敌人
- 4：石弹（mask=2，只打敌人）

### 关键导出参数
- `Player.move_speed`：默认 220；`max_hp` 默认 8；`hurt_invuln_seconds` 默认 0.6
- `MeleeWeapon.damage`：默认 1；`attack_range` 默认 72；`cooldown` 默认 0.45
- `RangedWeapon.damage`：默认 1；`attack_range` 默认 320；`cooldown` 默认 0.85
- `StoneProjectile.speed`：默认 420；`lifetime` 默认 2
- `Enemy.move_speed`：默认 120；`contact_damage` 默认 1；`max_hp` 默认 3
- `WaveConfig.enemy_count` / `spawn_interval`：见 `data/waves/*.tres`
- 场地半尺寸默认 `(480, 270)`，相关节点请保持一致

### 输入动作
`move_left` / `move_right` / `move_up` / `move_down`（WASD + 方向键）

### 分组
- 玩家：`player`
- 敌人：`enemies`

## 5. 资源替换约定
1. 美术只放 `assets/`，数值只放 `data/` 或脚本导出变量。
2. 替换贴图时保持路径与文件名不变，例如始终使用 `res://assets/sprites/player/player.png`。
3. 新增敌人/武器贴图时，先在对应子目录放占位图，再在场景里引用。
4. 不要在脚本里用绘制色块代替最终角色表现；占位也尽量走 `Sprite2D` + `assets/`。

## 参考来源与落地位置

### 1. Vampire Survivors Clone

- 来源：[项目](https://github.com/migalvalm/vampire-survivors-clone)、[剑攻击控制器](https://github.com/migalvalm/vampire-survivors-clone/blob/main/scenes/ability/sword_ability_controller/sword_ability_controller.gd)。仓库 MIT。
- 查阅到的结构：攻击控制器在计时到点后筛选范围内敌人，再产生攻击实例；升级修改攻击间隔或伤害。
- 本项目采用：武器只在冷却就绪时查询有效目标；基础配置与运行时模块加成分离。沿用单人木棍/弹弓，不引入参考项目的经验、升级选项或经济规则。
- 实现：`scripts/build/weapon_definition.gd`、`scripts/combat/combat_targeting.gd`、`scripts/weapons/`。当前保留线性最近目标查询，无需引入排序或空间索引。

### 2. GDQuest Action RPG

- 来源：[项目](https://github.com/gdquest-demos/godot-make-pro-2d-games)、[HitBox](https://github.com/gdquest-demos/godot-make-pro-2d-games/blob/master/actors/hit_box/HitBox.gd)。源码 MIT，原工程 Godot 3.1。
- 查阅到的结构：HitBox 把接触交给拥有者处理伤害，提供启停入口；项目将角色、武器、生命与受击系统分开。
- 本项目采用：目标合法性/伤害入口独立；木棍使用前摇 → 命中 → 收招，不在动画开始前直接扣血。石弹消耗状态在伤害回调前设置，防止同帧穿透；结束时关闭战斗对象而不是关闭结果 UI。
- 保留现有 `take_damage`、`defeated`、`damage_taken` 接口，避免大规模迁移生命组件。首领仍只有已确认的追近、冲撞、震地，不移植三阶段 Boss。
- 木棍前摇 0.06 秒、挥击 0.12 秒是临时测试值，基础伤害/冷却/范围沿用原值；这不是 P5 手动攻击对照。

### 6. Universal LPC Character Generator

- 来源：[项目与动画说明](https://github.com/LiberatedPixelCup/Universal-LPC-Spritesheet-Character-Generator)。工具代码 GPL-3.0；素材授权按具体条目及 CREDITS 区分，不能整体当作 CC0。
- 本项目采用：统一帧协议、各层共享动画时钟、明确图层排序与稳定外观 ID。生成器代码和插件没有进入工程；已从上游提交 `9bf06be193b053db256b2536824af426de046aa2` 复用身体、头、头发、上衣、裤子、凉鞋和弹弓的 `walk.png` 图层，署名与许可见 `assets/ulpc/CREDITS.md`。
- `AppearanceProfile` 定义图集尺寸、帧速及 `clips`。键为 `walk_right` 等，值为帧坐标数组，可覆盖默认 Ninja Adventure 布局。它不是通用 LPC 文件导入器，外部图集必须显式匹配协议。
- `AppearanceLayer` 定义 `item_id`、`layer_id`、`profile_id`、纹理、颜色及各方向绘制次序。`layer_id` 是渲染层身份，不是最终武器槽数量或玩法槽位规则。
- `layered_character.gd` 绑定在玩家与村落的身体 Sprite2D。`equip_layer()` 拒绝不同协议或尺寸；同层替换会立即移除旧渲染，`remove_layer()` 清除图层及记录；`equipped_ids()` 返回副本。
- 当前村落与单人战斗共用 `ulpc_walk_v1` 的 9×4 行方向协议和六个透明叠加层，待机取第 0 帧，行走循环 9 帧。完整攻击、受伤、死亡图层动画、衣服穿脱 UI、库存与跨场景装备状态尚未实现。

## 文档与代码冲突的处理

- **入口漂移**：README、概览、交接仍写旧的模式选择路径，现行代码已直达村落。已同步文档，保留旧场景用于历史原型。
- **撤离语义漂移**：旧文档写撤离立即结算，代码改成传送门却没有统计完成事件。保留回城体验，进门时独立发出 `run_returned_to_village`，只结束统计，不触发旧结果面板。
- **结束状态不完整**：波次停止但玩家、敌人与投射物继续更新。现在统一禁用战斗对象，HUD 和重新开始仍可工作。
- **配置身份和战斗值分裂**：武器定义只有展示信息，数值散落脚本和场景。现在单人从同一资源读取基础值，模块只产生派生值，不改写共享资源。
- **同帧重复伤害**：`queue_free()` 延迟释放不能阻止石弹再次碰撞。新增消耗标记并通过回归验证。
- **素材加载与发行风险**：原加载器用原始文件路径创建 ImageTexture。现在使用 Godot 导入资源，正式导出仍需单独验证。
- **工程配置残留**：不存在的 hd2d 插件仍在启用列表；自动加载探针依赖 UID 缓存。已清理失效项并给探针使用明确路径。
- **临时素材污染导入**：下载包与 macOS 元数据被当成资源扫描。`tmp/.gdignore` 隔离临时区，未删除用户文件。

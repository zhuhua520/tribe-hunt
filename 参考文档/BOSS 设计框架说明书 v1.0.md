# BOSS 设计框架说明书 v1.0

## 一、设计目标

BOSS 是区域探索与战斗的阶段性目标。

每个 BOSS 应当具有：

- 明确的战斗主题。
- 可辨认的核心攻击模式。
- 合理的攻击预警和恢复窗口。
- 与主题匹配的防护或特殊机制。
- 有意义的奖励。

BOSS 的难度不能只依赖生命值、攻击力和伤害范围的增加。

## 二、通用 BOSS 结构

### 1. 战斗开始

- 进入战斗状态。
- 展示必要的出场或警戒表现。
- 明确玩家与 BOSS 的交战空间。
- 不应在玩家尚未理解战斗已经开始时，直接造成无法规避的伤害。

### 2. 基础战斗循环

BOSS 在数个可辨认的攻击模式之间切换。

每种攻击都应有清晰的预警、生效和恢复阶段。玩家通过观察和走位找到反击机会。

### 3. 特殊机制

根据 BOSS 类型选择少量机制，例如：

- 护甲与破甲。
- 弱点暴露。
- 区域攻击。
- 阶段转换。
- 特殊部位破坏。
- 星象图案攻击。

不要求一个 BOSS 同时使用所有机制。

### 4. 战斗结束

- 正确处理死亡或击败状态。
- 播放必要的反馈。
- 发放奖励。
- 更新相关任务、探索进度或解锁状态。
- 避免重复触发奖励。

## 三、首个区域 BOSS：野猪王

### 核心定位

以冲锋、厚重身体和护甲为主题，验证基础攻击、闪避和破甲机制。

### 推荐动作

1. 普通冲撞：具有明确的起步和冲锋预警。
2. 强力冲锋：造成更大威胁，但结束后恢复时间更明显。
3. 近距离攻击：防止玩家始终贴身站在安全位置。
4. 破甲失衡：护甲积累达到阈值后，进入短暂失衡状态。

### 机制规则

- 护甲减免适用于配置好的装甲区域。
- 重锤和火铳具有较高的破甲贡献。
- 剑可以通过持续攻击积累破甲。
- 长弓可以寻找有效攻击位置或暴露弱点。
- 不应因为玩家选择了某一种武器而禁止其他打法。

### 奖励方向

区域材料、制造资源、特殊战利品及与区域探索相关的解锁。

具体掉落表待资源系统确定后编写。

## 四、首个遗迹 BOSS：古代机械守卫

### 核心定位

以失落文明造物、机械护甲和核心弱点为主题。

### 推荐动作

1. 机械近战攻击。
2. 直线或区域能量攻击。
3. 阶段性防御。
4. 核心暴露窗口。
5. 可选的装甲部位破坏。

### 机制规则

- 普通护甲、弱点与伤害使用统一命中结算。
- 核心暴露应有明确预警和持续时间。
- 永久部位破坏仅在能够改变战斗方式时启用。
- 部位破坏可以移除防护、暴露弱点或改变某种攻击方式。
- 不强制所有机械敌人拥有可破坏部位。

### 奖励方向

失落技术、制造图纸、机械材料或先进装备相关解锁。

## 五、星宿 BOSS 设计框架

### 核心定位

将中国古代星宿体系与失落文明的天文观测、能量控制和机械技术相结合。

星宿 BOSS 可以呈现神话色彩，但其力量在世界观中属于失落文明技术的特殊应用。

### 核心战斗机制

每个星宿 BOSS 至少需要：

1. 一种鲜明的星象主题。
2. 一种可辨认的攻击预警方式。
3. 一种主要攻击模式。
4. 一个可利用的反击窗口。
5. 一项与该 BOSS 主题相匹配的奖励。

### 推荐表现

- 星点在场地上标记危险位置。
- 星线或星图提示攻击方向。
- 特定星象组合触发区域攻击。
- BOSS 的装置或能量核心在特定时机暴露。
- 战斗阶段改变星象攻击的组合方式。

以上属于设计方向，不代表每个星宿 BOSS 都必须使用全部效果。

### 难度控制

- 星象预警应当清晰可辨。
- 多个攻击机制组合时，不能使安全区域难以判断。
- 不应仅通过快速连续生成大范围攻击提高难度。
- 玩家应能通过观察、走位和选择攻击时机找到应对方法。
- 特殊战斗规则应复用现有攻击、受击和伤害系统。

### 奖励方向

可以包括：

- 星宿组件。
- 与星宿相关的特殊战利品。
- 探索和技术资源。
- 特殊外观或其他非战斗奖励。

具体星宿对应关系、组件属性和 Build 规则由独立文档负责。

## 六、BOSS 数值设计原则

首轮不锁定具体数值。

生命值、攻击伤害、攻击间隔、破甲阈值和阶段触发条件应在基础战斗系统稳定后，通过实际测试确定。

BOSS 的不同阶段应优先体现行为变化，而不是简单地在第二阶段增加所有数值。

## 七、验收标准

1. BOSS 的核心机制容易辨认。
2. 玩家可以通过观察和操作应对攻击。
3. 不同 BOSS 具有明显的战斗差异。
4. 护甲、弱点和破甲行为符合统一规则。
5. 星宿 BOSS 与普通区域 BOSS、遗迹 BOSS 有明显区别。
6. 击败 BOSS 后正确发放奖励并更新进度。

# 玩家角色核心设计说明书 v1.0

**项目类型：** 2D 像素动作游戏  
**世界观：** 文明重启后的架空世界，玩家探索怪物盘踞的遗迹，获取资源并恢复失落文明技术。  
**文档状态：** 设计基线，待原型验证

## 一、设计目标

玩家是能够自由选择装备与战斗风格的探索者，不采用首版固定职业体系。

玩家的主要成长来源为：

1. 角色等级提供适度的基础属性成长。
2. 武器和护具决定主要战斗表现。
3. 失落技术解锁新的制造能力、装备和特殊机制。
4. 探索与战斗提供材料、图纸及其他成长资源。

玩家的成长不应只表现为伤害数字持续增加，还应体现为能够探索新的区域、使用新的装备和应对新的敌人。

## 二、基础控制

玩家首版需要具备以下操作：

- 左右移动。
- 跳跃与空中移动。
- 普通攻击。
- 重攻击或武器专属攻击。
- 闪避。
- 武器切换。
- 交互与拾取。
- 受击、死亡及必要的恢复操作。

具体键位由实际输入设备决定，不在设计阶段固定。

### 通用规则

- 移动、跳跃、闪避和受击使用共享的角色基础系统。
- 武器决定具体攻击动作，不同类别不能只更换外观和伤害数值。
- 闪避不消耗耐力。
- 攻击不能在任何时刻自由取消，继续沿用武器动作承诺和取消窗口规则。
- 输入缓冲用于改善攻击衔接，但不能绕过装填、蓄力和攻击阶段限制。

## 三、基础属性

首版仅保留必要的核心属性。

### 1. 生命值

决定玩家能够承受的伤害。

- 角色升级可以适度提高生命上限。
- 护具及特殊装备可以提供额外生存能力。
- 恢复道具的种类、效果与数量限制待定。

### 2. 基础攻击能力

作为角色成长对输出的基础贡献。

- 角色等级可以提供有限的攻击成长。
- 武器基础伤害、攻击动作和攻击专属机制由武器系统决定。
- 不应让角色升级直接抹平不同武器的战斗特色。

### 3. 防御能力

主要由护具及相关装备提供。

- 防御影响受到攻击时的伤害结算。
- 不以防御数值完全替代闪避和走位。
- 不设置可无限自由加点的独立防御属性。

暴击率、命中率、耐力、韧性、元素抗性等暂不纳入首版核心属性。

## 四、玩家成长

采用混合成长方案。

### 角色等级

- 自动成长，不开放自由属性点分配。
- 提供适度的基础生命成长。
- 提供有限的基础攻击成长。
- 不直接解锁大量新的攻击动作。
- 具体经验来源、等级上限和成长曲线待测试后确定。

### 装备成长

装备决定主要战斗表现。

- 武器决定攻击方式、动作节奏和专属机制。
- 护具决定主要防护能力。
- 不同品质的同类武器可以复用动作框架。
- 装备强化、品质和随机词条属于后续装备系统设计范围。

### 技术成长

技术来源于失落文明的遗迹、图纸、材料和装置。

技术可以解锁：

- 新武器与装备的制作能力。
- 特殊弹药和战斗工具。
- 新的攻击机制。
- 更先进的制造能力。
- 探索和基地相关功能。

技术成长不应只提供数值增加，还应尽可能解锁新的玩法可能。

## 五、玩家受击规则

- 玩家受到有效攻击后，执行统一伤害结算。
- 命中应具有清晰的视觉、音效和动作反馈。
- 受击后建议具有短暂无敌时间，避免玩家因连续碰撞而无法反应。
- 无敌时间的持续长度、闪烁表现和特殊攻击例外待测试确定。
- 无敌状态不能自动免疫所有环境伤害或特殊状态，具体规则应明确配置。
- 不同敌人的攻击可以产生不同击退和受击反应，但不能随意绕过统一受击机制。

## 六、玩家死亡与长期进度

首版建议采用以下规则：

- 死亡后进入明确的失败或复活流程。
- 已解锁的技术和永久成长应予以保留。
- 不因一次死亡清空全部长期进度。
- 具体复活位置、恢复方式和资源损失规则暂缓决定。
- 死亡惩罚应与探索风险相匹配，不能在未明确规则前默认掉落全部资源。

## 七、首版不做的内容

- 复杂的自由属性加点。
- 大量重复的核心属性。
- 完整职业和技能树系统。
- 耐力消耗型闪避。
- 过多独立的战斗资源条。
- 尚未验证的复杂异常状态系统。

## 八、验收标准

1. 玩家可以完成基础移动、跳跃、闪避、攻击和交互。
2. 不同武器具有明确的操作差异。
3. 角色升级不会让所有武器逐渐变得相同。
4. 装备和技术能够产生独立且可感知的成长价值。
5. 玩家受击、无敌和死亡规则稳定、可预测。
6. 长期成长不会因为单次死亡而被意外清空。

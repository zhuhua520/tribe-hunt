# 武器系统核心规则 v0.1

## 1. 项目背景

游戏设定于文明重启后的架空世界。玩家探索被怪物占据的文明遗迹，获取资源、武器、图纸和失落技术，逐步恢复制造能力。

魔法与神话力量主要通过失落文明遗留的先进技术解释。技术进步不仅提升武器性能，也可以解锁新的攻击机制。

## 2. 武器系统目标

1. 不同武器类别必须具有明显不同的攻击动作和战斗体验。
2. 武器成长应体现技术进步，而非仅仅提升伤害数值。
3. 玩家通过探索、战斗、修复和制作获得武器及新能力。
4. 传统武器类别可以通过后续技术获得新机制，不因火器出现而整体失去价值。
5. 控制首发制作规模，先验证少量原型，再扩充武器种类。

## 3. 武器分类

一级分类：

- 近战武器
- 远程武器

首批原型：

| 武器 | 类别 | 核心体验 |
|---|---|---|
| 剑 | 近战 | 连击、灵活衔接 |
| 重锤 | 近战 | 蓄力、破甲、失衡 |
| 长弓 | 远程 | 瞄准、蓄力、精准射击 |
| 单发火铳 | 远程 | 高冲击、开火时机、装填 |

长枪、机械连弩、共振刃、导引弓、脉冲步枪暂列候选目录。

## 4. 技术成长

技术阶段与武器类别分离。

技术方向包括：

- 生存制造：木材、石材、骨材及简易加工。
- 工业技术恢复：金属冶炼、机械结构、精密加工。
- 火药技术恢复：枪械结构、火药和弹药制造。
- 失落科技复原：特殊材料、古代装置、先进控制技术。

这些阶段不是严格的线性淘汰路线。玩家可以发现无法立即制造的先进遗物，也可以通过后续探索修复或掌握其制造方法。

## 5. 基础战斗规则

- 所有武器共享角色移动、跳跃、闪避、受击等基础系统。
- 每类武器拥有独立的攻击逻辑。
- 攻击动作划分为前摇、生效和后摇。
- 使用输入缓冲改善攻击衔接。
- 不允许所有攻击在任何时刻自由取消。
- 不引入耐力消耗系统；以动作时长、攻击承诺和取消窗口控制战斗节奏。
- 闪避不应被设计成可以随时取消所有攻击后果的万能操作。

## 6. 开发顺序

1. 剑：验证基础攻击、连击和取消规则。
2. 重锤：验证蓄力、破甲与动作承诺。
3. 长弓：验证远程攻击、瞄准和移动。
4. 火铳：验证高冲击射击、装填和弓箭差异。

第一阶段不锁定最终伤害、攻击帧数、品质、强化或随机词条。

## 7. 验收原则

每种武器必须在操作节奏、攻击方式或战术选择上形成可感知的区别。后续新增同类武器时，应尽量复用类别级动作框架。

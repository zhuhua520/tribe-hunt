# 攻击判定实现与 QA 测试计划 v1.0

## 1. 实现目标

实现一套能够支持近战关键帧判定、远程投射物、统一命中结算、护甲、弱点及破甲机制的基础系统。

第一阶段只要求支持剑、重锤、长弓、单发火铳，以及野狼、厚甲野猪和遗迹守卫三种测试敌人。

## 2. 建议的模块划分

### Attack Data

管理攻击动作及参数：

- 攻击类型和标识。
- 前摇、生效与后摇。
- 关键帧判定区域。
- 伤害参数。
- 破甲贡献。
- 击退和受击反馈。
- 取消窗口。

### Projectile System

管理：

- 投射物生成。
- 移动与轨迹。
- 连续碰撞检测。
- 穿透规则。
- 命中与销毁。

### Enemy Hit Regions

管理：

- 普通受击区域。
- 护甲区域。
- 弱点区域。
- 区域激活条件。
- 区域优先级。

### Hit Resolver

统一处理：

- 命中有效性检查。
- 每次攻击的目标去重。
- 命中区域判断。
- 伤害与护甲减免。
- 破甲值更新。
- 弱点收益。
- 目标状态变化。

### Armor Break State

管理：

- 破甲积累。
- 破甲触发。
- 破甲状态持续。
- 破甲结束与恢复。
- Boss 特殊部位破坏状态。

这些是逻辑职责划分，不要求必须实现为五个独立程序文件或五个独立组件。

## 3. 第一阶段实现顺序

1. 建立普通受击区域与统一命中结算。
2. 实现剑的关键帧判定和扫掠检测。
3. 实现重锤的攻击判定及破甲贡献。
4. 实现箭矢投射物。
5. 实现高速子弹的连续碰撞检测。
6. 增加护甲与弱点区域。
7. 增加普通破甲状态。
8. 最后加入 Boss 永久部位破坏的最小验证样例。

每一步通过基础测试后再继续下一步。

## 4. 功能测试清单

### 近战判定

- [ ] 前摇期间不会提前造成伤害。
- [ ] 生效阶段能够正常命中。
- [ ] 后摇阶段不残留攻击判定。
- [ ] 快速挥动不会频繁漏判。
- [ ] 同一攻击实例不会重复伤害同一目标。
- [ ] 同一攻击实例可以命中多个不同目标。
- [ ] 连击不同阶段可以独立命中。
- [ ] 角色转向后判定区域正确翻转。

### 投射物

- [ ] 发射前不生成有效攻击。
- [ ] 箭矢按照配置的轨迹移动。
- [ ] 高速子弹不会穿过薄目标。
- [ ] 普通投射物命中首个有效目标后停止。
- [ ] 地形能够正确阻挡投射物。
- [ ] 投射物不会在生成时误伤发射者。
- [ ] 投射物超出有效距离或寿命后正确销毁。

### 区域判定

- [ ] 普通受击区域正常工作。
- [ ] 护甲区域能够正确减伤。
- [ ] 未暴露的弱点不会错误生效。
- [ ] 实际命中弱点能够获得相应收益。
- [ ] 护甲与弱点重叠时结果稳定。
- [ ] 目标死亡后不会继续接收普通伤害结算。

### 破甲

- [ ] 不同攻击具有不同的破甲贡献。
- [ ] 达到阈值后触发破甲。
- [ ] 破甲期间不继续积累下一轮破甲值。
- [ ] 普通敌人破甲结束后恢复护甲。
- [ ] Boss 的特殊破甲规则不影响普通敌人。
- [ ] 永久部位破坏不会自动恢复。
- [ ] 破甲和部位破坏不会重复触发错误的阶段转换。

## 5. 场景验收

### 野狼

验证快速近战、连续攻击和移动目标的判定可靠性。

重点检查剑的连击、重锤的攻击窗口、箭矢对高速目标的命中，以及火铳在装填期间的战斗节奏。

### 厚甲野猪

验证护甲减伤、破甲积累和短暂失衡。

确保重锤和火铳拥有各自的破甲优势，同时剑与长弓仍能通过有效战术造成伤害。

### 遗迹守卫

验证护甲、弱点暴露与 Boss 阶段转换。

检查破甲是否产生有意义的进攻窗口，以及永久部位破坏是否能够改变后续战斗。

## 6. 边界与回归测试

- 攻击目标在命中过程中死亡。
- 攻击动画被闪避或受击打断。
- 两个敌人紧密重叠。
- 护甲与弱点区域发生重叠。
- 投射物与地形、敌人在同一次物理更新中接近。
- 攻击区域在角色转向时翻转。
- 破甲阈值恰好被一次攻击达到。
- Boss 部位破坏与阶段转换同时发生。
- 同一目标受到不同攻击实例的连续命中。

## 7. 调试工具要求

开发阶段建议提供：

- 攻击判定区域显示。
- 敌人受击区域显示。
- 护甲和弱点区域显示。
- 投射物路径与碰撞位置显示。
- 当前攻击阶段显示。
- 每次攻击已命中目标的列表。
- 当前破甲值与破甲状态显示。
- Boss 部位状态显示。

破甲数值可以在调试界面显示，即使正式游戏不显示精确数值。

## 8. 验收标准

系统满足以下条件后，可以进入武器数值平衡阶段：

1. 基础命中稳定，没有明显的穿模漏判。
2. 单次攻击不会意外重复伤害。
3. 不同武器采用适合自身的判定方式。
4. 护甲和弱点规则稳定、可预测。
5. 普通破甲不会造成无限控制。
6. Boss 部位破坏能够与普通破甲正确区分。
7. 新增同类武器时能够复用现有系统。
8. 伤害、破甲和反馈参数可以独立调整。

只有通过测试后，才进一步确定具体伤害、破甲阈值、恢复时长和各武器的最终平衡参数。

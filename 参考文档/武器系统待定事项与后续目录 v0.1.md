# 武器系统待定事项与后续目录 v0.1

## 一、暂缓决定的系统

以下内容不属于当前原型阶段的必需范围：

- 武器品质与稀有度。
- 强化等级与数值成长曲线。
- 随机词条。
- 制作配方与材料数量。
- 完整的技术解锁树。
- 特殊弹药的制作与携带规则。
- 失落科技武器的详细能量机制。
- 后期武器的具体数值平衡。
- 星宿 Build 与武器的联动规则。

后续在基础战斗原型稳定后再逐项确定。

## 三、后续扩展原则

1. 新武器首先需要明确的战斗定位。
2. 同类别武器优先复用动作框架。
3. 只有改变核心攻击方式时，才增加独立动作体系。
4. 新技术应优先提供新的战斗机制，而不只是增加伤害。
5. 不强制旧武器类别在所有数值上与新武器相等，但应避免整个类别彻底失去玩法价值。

## 四、下一阶段建议

基础原型通过测试后，再按以下顺序扩展：

1. 调整四种原型的动作时序与取消窗口。
2. 确定伤害、攻击范围、硬直和装填等基础参数。
3. 设计同类别的第二把武器，验证复用能力。
4. 引入品质、强化和随机词条设计。
5. 逐步恢复失落科技武器的制造与解锁流程。

# 第二批历史资料目录：北方玄武七宿

本批整理斗、牛、女、虚、危、室、壁七宿。资料采用香港太空馆《中国星区、星官及星名英译表》作为工作目录，并用《步天歌（何君藩）》的在线文本交叉核对名称、排列和部分星数。两者不是同一版本的目录，不能直接合并为一份所谓的古代标准名单。&#x20;

## 九、本批次发现的主要版本与层级问题

| 编号   | 涉及条目   | 问题              | 当前处理      |
| ---- | ------ | --------------- | --------- |
| N-01 | 天龠／天籥  | 用字差异            | 保留来源原文    |
| N-02 | 女宿·十二国 | 一个星官下包含十二个国名    | 父子层级分开    |
| N-03 | 璃瑜／离瑜  | 用字差异            | 暂不强行统一    |
| N-04 | 危·坟墓   | 网页列在危的关联星名栏     | 不擅自新增顶层条目 |
| N-05 | 室·离宫   | 网页列在室的关联星名栏     | 保留父子关系    |
| N-06 | 斗、牛、危等 | 歌诀出现其他天区名称      | 不直接归入本宿   |
| N-07 | 壁宿·火鸟  | 歌诀有相关文字，当前目录未单列 | 暂存待核验     |

香港太空馆说明，古代星官体系经历过历史发展与后世星表修订，因此名称、星数及分类不能脱离来源版本单独判断。

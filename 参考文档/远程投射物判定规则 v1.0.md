# 远程投射物判定规则 v1.0

## 1. 适用范围

适用于长弓箭矢、火铳子弹，以及未来的特殊弹药和失落科技投射物。

## 2. 基本生命周期

投射物通常经历：

1. 待发射。
2. 生成。
3. 飞行。
4. 碰撞判定。
5. 命中或撞击反馈。
6. 销毁或执行特殊后续行为。

只有武器攻击到达实际发射时刻，才生成投射物。

## 3. 通用投射物数据

| 字段 | 用途 |
|---|---|
| projectile_id | 投射物类型标识 |
| spawn_offset | 相对发射点的偏移 |
| collision_shape | 投射物碰撞形状 |
| speed | 飞行速度 |
| trajectory | 运动轨迹配置 |
| max_lifetime | 最大存在时间 |
| max_range | 最大有效飞行距离 |
| penetration | 是否允许穿透 |
| hit_profile | 命中后使用的伤害与反馈规则 |
| impact_effect | 命中特效或撞击效果 |

具体速度、寿命、射程和轨迹参数待测试确定。

## 4. 长弓箭矢

### 发射

- 蓄力或快速射击动作在发射时刻生成箭矢。
- 箭矢从合理的发射位置生成。
- 箭矢初始方向与角色朝向、瞄准方向或武器设定一致。

### 飞行

- 箭矢作为独立对象移动。
- 可以根据武器设计采用直线或带重力的轨迹。
- 箭矢的视觉方向应与运动方向保持合理一致。
- 未来特殊箭矢可以拥有独立轨迹，但不改变基础碰撞规则。

### 碰撞

- 默认命中第一个有效目标后停止。
- 普通箭矢不默认穿透多个敌人。
- 命中护甲、身体或弱点时进入统一命中结算。
- 命中后播放对应效果，再销毁或按箭矢规则处理。

## 5. 火铳子弹

### 发射

- 只有已装填且攻击动作到达发射时刻时才能开火。
- 子弹从枪口或配置的发射点生成。
- 子弹初始方向依据瞄准规则确定。

### 飞行

- 子弹默认采用高速直线移动。
- 首轮不要求加入弹道下坠、风偏或复杂弹道模拟。
- 子弹飞行速度可以明显高于普通箭矢，但速度不代表自动命中。

### 连续碰撞检测

高速子弹不能只检测每帧结束时的位置。

应检查子弹上一位置到当前位置之间的运动路径，避免子弹在两个物理更新时刻之间穿过薄目标。

### 碰撞

- 默认命中第一个有效目标后停止。
- 命中地形障碍时按实际碰撞顺序停止。
- 命中目标后触发统一结算与火器专属反馈。
- 不允许通过高速度绕过护甲、弱点或目标无敌状态的规则。

## 6. 穿透规则

普通箭矢和普通子弹默认不穿透目标。

穿透必须作为显式能力配置，并至少明确：

- 可以穿透哪些目标类型。
- 最多能够命中多少目标，或采用什么终止条件。
- 后续命中是否降低伤害。
- 穿透护甲与穿透身体是否使用不同规则。
- 穿透后是否继续飞行，以及何时销毁。

首轮原型不要求实现这些高级规则。

## 7. 碰撞顺序

当投射物可能同时接触地形、护甲和身体时，应根据运动轨迹上最先发生的有效碰撞处理，而不是任意选择一个碰撞结果。

当护甲和弱点区域重叠时，按照目标区域配置和实际碰撞位置确定命中部位。

投射物生成时应忽略发射者自身的碰撞区域，避免刚生成就击中玩家。

## 8. 生命周期与安全边界

- 投射物应具有最大存在时间或最大有效距离。
- 失效、超出范围或命中后应按规则销毁。
- 不允许投射物无限累积。
- 销毁后必须正确释放碰撞与命中记录。
- 未来如存在友军或中立单位，应明确配置目标过滤规则。

## 9. 验收标准

- 箭矢和子弹不会在发射前命中。
- 高速子弹不会频繁穿过薄目标。
- 普通投射物命中第一个有效目标后停止。
- 墙壁能够正确阻挡投射物。
- 弱点命中必须满足区域与状态条件。
- 投射物的伤害、破甲和反馈均通过统一命中结算处理。

# 攻击判定核心规则 v1.0

**适用范围：** 2D 像素动作游戏  
**适用武器：** 剑、重锤、长弓、单发火铳及后续扩展武器  
**文档状态：** 设计基线，待原型实现与测试

## 1. 设计目标

1. 攻击判定应尽可能符合玩家看到的攻击动作。
2. 不同武器采用适合自身特点的判定方式。
3. 所有攻击共用统一的命中结算规则。
4. 避免漏判、重复伤害和不合理的弱点命中。
5. 支持后续增加特殊箭矢、穿透弹、范围攻击、失落科技武器及 Boss 部位机制。
6. 避免逐像素碰撞和过度复杂的部位模拟。

## 2. 基本术语

- **攻击实例：** 一次独立的攻击行为，例如剑的第一段斩击、一次重锤挥击或一发子弹。
- **攻击判定区域：** 攻击能够命中目标的区域。
- **受击区域：** 敌人能够被攻击命中的区域。
- **护甲区域：** 能够提供防护并参与破甲机制的区域。
- **弱点区域：** 在满足暴露条件时提供特殊命中收益的区域。
- **投射物：** 由弓箭、火铳等远程武器发射并独立移动的攻击对象。
- **扫掠检测：** 检查攻击区域从上一个位置移动到下一个位置时经过的空间，避免高速运动漏判。

## 3. 武器判定方案

### 3.1 近战武器

采用关键帧判定。

攻击动画中的少量关键帧定义攻击区域的位置、大小和有效阶段。引擎通过相邻关键帧之间的扫掠检测，减少快速挥动时的漏判。

不采用严格的逐像素碰撞。

### 3.2 远程武器

弓箭和火铳采用独立投射物。

- 箭矢具有独立的移动轨迹和碰撞判定。
- 子弹具有独立的高速移动判定。
- 高速子弹使用连续碰撞检测或等效的扫掠检测。
- 投射物不能在生成瞬间自动命中目标，除非未来某种武器被明确设计为射线或瞬时攻击。

### 3.3 统一命中结算

不同判定方式产生的命中事件，最终进入统一结算流程。

1. 检测攻击与有效受击区域的碰撞。
2. 确认命中部位及目标状态。
3. 检查该攻击实例是否已经命中过该目标。
4. 计算基础伤害、护甲减免、弱点收益和其他适用效果。
5. 更新生命值、破甲值及相关战斗状态。
6. 触发受击动画、命中特效、音效和击退等反馈。

各武器不应各自维护一套互不兼容的伤害结算逻辑。

## 4. 命中次数规则

默认规则：

- 一次攻击可以命中多个不同敌人。
- 同一次攻击实例默认只能对同一个敌人结算一次伤害。
- 多段连击的每一段属于独立攻击实例。
- 持续伤害、旋转多段攻击、穿透和重复命中需要显式配置。
- 不能因为攻击判定连续多个游戏帧与同一目标重叠，就反复造成伤害。

单次攻击的目标命中记录，应与该攻击实例绑定，而不是简单地与整个武器绑定。

## 5. 默认穿透规则

- 普通箭矢命中第一个有效目标后停止。
- 普通子弹命中第一个有效目标后停止。
- 近战攻击可以命中判定区域内的多个敌人。
- 特殊穿透能力必须明确配置，不作为所有远程武器的默认能力。

投射物如果先撞到阻挡攻击的墙壁或地形，应按照实际碰撞顺序处理，不能穿过障碍物命中后方敌人。

## 6. 敌人碰撞区域

需要区分：

1. 身体碰撞区域：用于移动阻挡和身体接触。
2. 受击区域：用于接收攻击。
3. 护甲区域：用于护甲减伤和破甲。
4. 弱点区域：用于特殊命中收益。

普通敌人默认只需要基础受击区域。只有具备明确玩法价值的敌人，才增加护甲和弱点区域。

碰撞形状优先采用可调整的矩形、圆形或胶囊形，不追求与精灵图每个像素完全重合。

## 7. 护甲与弱点规则

- 护甲影响命中伤害，并可积累破甲值。
- 弱点只有在满足暴露条件时才生效。
- 必须实际命中弱点区域，不能因为攻击框擦到弱点附近就自动获得弱点收益。
- 当护甲与弱点区域重叠时，依据实际碰撞位置及预先配置的区域规则确定命中部位。
- 无法稳定区分接触位置时，采用明确的区域优先级，避免随机判定。
- 弱点命中是否增加破甲值由目标规则决定，默认不增加普通护甲的破甲值。

## 8. 破甲规则

- 破甲值仅对启用该机制的敌人维护。
- 不同武器和攻击类型具有不同的破甲贡献。
- 达到阈值后触发破甲状态。
- 普通装甲敌人在破甲期间暂时失去相关护甲减伤。
- 精英怪和 Boss 可以采用部分减伤或指定部位暴露的特殊规则。
- 破甲期间不积累下一轮破甲值。
- 破甲结束后，普通护甲恢复，破甲值重置。
- 永久部位破坏是独立机制，仅用于专门设计的 Boss。

## 9. 开发边界

首轮原型不要求实现：

- 逐像素碰撞。
- 所有敌人的复杂部位系统。
- 所有投射物的穿透与反弹。
- 完整的物理材料模拟。
- 所有 Boss 的永久部位破坏。

优先完成剑、重锤、长弓和火铳的基础判定，再依据测试结果扩展。

# 星宿武装系统 v0.2
## 核心规则与组件数据规范

### 一、设计目标

玩家不需要记住完整的中国古代天文知识，也不需要背诵各种套装触发条件。

玩家只需要理解：

- 星宿决定一种核心战斗机制。
- 星官提供强化、转换或补充效果。
- 星级决定组件的基础品质。
- 强化等级决定数值成长。
- 元素值决定对应元素的属性贡献。
- 武器适配标签决定组件适用于哪些武器。
- 特殊词条决定组件独有的战斗效果。

三垣、二十八宿和星官的历史体系主要负责内容组织、名称、背景和收集关系，不额外增加一套玩家必须记忆的战斗规则。

## 二、唯一的核心装配规则

每把武器拥有三个星位：

| 星位 | 装配内容 | 作用 |
|---|---|---|
| 核心位 | 1 个星宿 | 确定核心战斗机制 |
| 辅助位 A | 1 个星官 | 强化或改变核心机制 |
| 辅助位 B | 1 个星官 | 强化或改变核心机制 |

记忆口诀：**一宿两官。**

### 唯一的套装规则：本宿共鸣

如果两个辅助位装备的星官都归属于核心位的星宿，则激活该星宿的专属共鸣。

如果两个星官来自不同星宿，它们的特殊词条仍然正常生效，只是不触发本宿共鸣。

例如：

- 角宿 + 进贤 + 天田：触发角宿共鸣。
- 角宿 + 进贤 + 砺石：三个组件的独立词条生效，但不触发角宿共鸣。

每个星宿只需要定义一个共鸣效果。第一版不增加四象套装、三垣套装、2/4/6 件套、元素阈值等额外规则。

## 三、统一的组件数据规范

所有星宿和星官使用同一套数据字段，区别仅在于类别及其设计职责。

| 属性 | 规范 | 作用 |
|---|---|---|
| 名称 | 唯一名称 | 辨认组件 |
| 类别 | 星宿 / 星官 | 决定组件职责 |
| 初始星级 | 1—5 星 | 决定初始品质和基础数值档位 |
| 强化等级 | +0 至 +5 | 提升组件的数值属性 |
| 元素类型 | 木、火、土、金、水 | 指定元素属性类别 |
| 元素值 | 数值 | 增加武器对应的元素属性 |
| 武器适配标签 | 剑、长柄、弓弩、重武器、通用等 | 限定可装配的武器类型 |
| 特殊属性词条 | 一条核心效果 | 决定独特的战斗行为 |
| 所属关系 | 所属星宿或天区 | 用于本宿共鸣、图鉴和内容组织 |

### 星级与强化等级必须分开

**初始星级**是组件获取时确定的品质，不随普通强化改变。

**强化等级**是玩家通过材料提升的成长等级。

建议第一版采用以下规则：

- 星级越高，初始数值档位越高，特殊词条的数值上限也可以更高。
- 强化等级只提升数值，不改变词条的触发条件，不增加新的特殊效果。
- 每个组件始终只有一条主要特殊词条，避免高星组件同时携带多条规则。
- 不允许强化直接改变组件类别或所属关系。

这样玩家只需要区分“这个组件初始品质如何”和“我把它强化到了几级”。

### 元素值的处理

每个组件具有一个主要元素类型及其元素值。

例如：

- 角宿：木元素 12。
- 进贤：木元素 5。
- 天田：土元素 4。

装配后，武器分别累加各元素的数值，直接用于对应元素伤害或元素积累。

第一版不增加五行相生相克、同元素阈值或复杂的元素共鸣。五行先作为清晰可读的属性类别使用，之后再根据战斗需求决定是否扩展。

### 武器适配标签

武器适配标签只负责判断能否装配，不同时承担套装加成。

例如：

- 长柄：适配枪、矛等武器。
- 重武器：适配大剑、战锤等武器。
- 弓弩：适配远程投射武器。
- 通用：适配所有武器。

特殊词条的触发条件与武器适配标签分开管理。这样不会出现玩家看到“适配长柄”，却不知道它究竟是限制装备，还是额外提高长柄伤害的问题。

## 四、组件数据示例

以下数值仅用于验证设计，正式数值需要经过游戏实测。

### 角宿

| 属性 | 示例值 |
|---|---|
| 类别 | 星宿 |
| 初始星级 | 4 星 |
| 强化等级 | +0 |
| 元素 | 木 12 |
| 武器适配 | 长柄、重武器 |
| 特殊词条 | 蓄力攻击命中时，额外积累破甲值 |
| 本宿共鸣 | 对已破甲的敌人发动重击时，产生一次额外冲击 |

角宿的设计目标是建立蓄力、破甲和重击流派。

### 进贤

| 属性 | 示例值 |
|---|---|
| 类别 | 星官 |
| 初始星级 | 3 星 |
| 强化等级 | +0 |
| 元素 | 木 5 |
| 武器适配 | 长柄、重武器 |
| 所属星宿 | 角宿 |
| 特殊词条 | 蓄力攻击命中精英敌人时，额外积累破甲值 |

进贤本身不需要额外的复杂机制。它的作用是强化角宿的蓄力破甲路线。

### 天田

| 属性 | 示例值 |
|---|---|
| 类别 | 星官 |
| 初始星级 | 2 星 |
| 强化等级 | +0 |
| 元素 | 土 4 |
| 武器适配 | 长柄、重武器 |
| 所属星宿 | 角宿 |
| 特殊词条 | 对处于破甲状态的敌人发动重击时，额外造成伤害 |

天田将角宿的破甲机制进一步转化为重击收益。

## 五、玩家实际能够形成什么 Build？

### Build A：角宿破甲流

角宿 + 进贤 + 天田

- 角宿负责蓄力破甲。
- 进贤强化对精英敌人的破甲效率。
- 天田强化对破甲目标的重击伤害。
- 两枚星官均归属于角宿，激活角宿共鸣。

玩家只需要理解一个战斗循环：蓄力破甲，然后重击。

### Build B：角宿混合流

角宿 + 进贤 + 其他星宿所属的星官

- 角宿负责破甲。
- 进贤强化破甲效率。
- 第三件组件提供另一种机制，例如暴击、闪避或元素积累。
- 因为不是两个角宿所属星官，所以不触发角宿共鸣。

这套配置牺牲专属共鸣，换取更广泛的战斗能力。

### Build C：其他星宿核心流

换掉角宿，装备另一个星宿作为核心，再根据它的特殊词条挑选两个星官。

这样玩家探索 Build 的主要过程就变成：

**选择核心机制 → 寻找适配星官 → 决定是否追求本宿共鸣。**

不需要再学习额外的套装层级。

## 六、内容扩展规范

后续制作二十八宿时，每个星宿只需要填写：

1. 一个核心特殊词条。
2. 一个本宿共鸣效果。
3. 一组所属星官。
4. 每个星官的一条特殊词条。
5. 每个组件的星级、强化、元素值和武器适配标签。

三垣用于组织高级区域、Boss 解锁路线和图鉴；二十八宿负责提供核心流派；星官负责组合变化。

这些历史层级不再分别生成新的套装规则。

## 七、第一阶段验收标准

第一版先制作 4 个星宿，每宿配置 3—4 个星官。

重点验证：

- 玩家能否在短时间内理解“一宿两官”。
- 更换星宿是否会明显改变战斗打法。
- 更换星官是否能够改变同一个星宿的 Build 路线。
- 本宿共鸣是否足够直观，值得玩家追求。
- 星级和强化是否容易理解，且不会让低星组件彻底失去用途。
- 不同武器是否能形成不同的有效组合。

在这些条件满足前，不增加更多套装规则、元素克制或复杂的跨天区共鸣。

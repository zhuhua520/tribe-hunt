# 三垣、二十八宿与星官历史资料目录
## 目录基准与总索引 v0.1

**用途：** 为游戏星宿武装系统建立可核验、可追溯的历史资料基础。

**当前状态：** 总目录已建立；具体星官条目需要逐项校核。

## 一、资料使用规范

### 1. 主参考资料

**《步天歌》（王希明本）**

主要用途：

- 作为三垣、二十八宿的目录组织参考。
- 记录传统星宿名称和相关星官的排列。
- 为游戏图鉴、区域组织及历史背景提供参考。
- 记录文本中出现的星官名称及其所在章节。

### 2. 交叉核验资料

**香港太空馆《中国星区、星官及星名英译表》**

主要用途：

- 对照整理后的星官名单。
- 核验星官名称及其相关恒星名称。
- 了解后世星表修订后的分类与恒星对应。
- 发现不同版本之间的名称、归属和数量差异。

该表反映的是经过后世整理的中国传统星区资料，不能直接等同于《步天歌》原文。

### 3. 版本处理原则

遇到不同资料之间的差异时：

1. 保留各来源的原始记录。
2. 标注来源、版本和对应章节。
3. 区分名称差异、星数差异、归属差异及后世增补。
4. 不擅自把不同版本的内容拼接成一个历史上从未存在过的目录。
5. 尚未核验的条目标记为“待核验”，不进入正式游戏历史资料。

## 四、星官条目的层级规范

每个星官应作为独立历史资料条目保存，并至少记录：

| 字段 | 说明 |
|---|---|
| history_id | 历史资料唯一标识 |
| standard_name | 标准名称 |
| aliases | 已核实的异名 |
| source_version | 来源版本 |
| source_location | 所在垣或宿及原文位置 |
| constituent_stars | 对应的具体星名，已核验时填写 |
| star_count | 对应版本记载的星数 |
| historical_status | 已核验、待核验、有争议 |
| source_reference | 文献或星表引用 |
| discrepancy_notes | 与其他版本的差异 |

### 特别注意

同名星官不应仅凭名称自动合并。

例如，天田在不同天区的目录中均有出现。建立数据库时，应先根据来源版本和天区位置区分记录，再核验它们之间的历史关系。

星官内部的具体星名也应独立记录，不能将一个星官及其组成恒星当作同一级条目。

## 六、历史资料与游戏设计分离

历史资料层记录：

- 星宿和星官的标准名称。
- 传统分类与归属。
- 对应恒星及星数。
- 文献来源和版本差异。

游戏内容层另行记录：

- 是否进入战斗 Build。
- 是否成为 Boss 或区域奖励。
- 是否用于时装、基地设施、探索或图鉴。
- 游戏中关联的星宿和星官。
- 原创战斗机制及奖励设计。

历史归属不因游戏内的关联、掉落或套装设计而改变。

# 临时借用素材

当前场景的临时美术取自 Pixel-Boy 与 AAA 的 [Ninja Adventure Asset Pack](https://pixel-boy.itch.io/ninja-adventure-asset-pack)。素材页标注为 CC0；此目录只保留了本项目展示所需的 PNG 子集，原始素材和派生贴图放在 `ninja_adventure/`。

| 项目资源 | 来源素材 | 用途 |
| --- | --- | --- |
| `player_sheet.png` | `character/ninja_blue/sprite.png` | 村落与战斗玩家，四方向与走路帧 |
| `boar_sheet.png` | `character/pig/pig.png` | 普通野猪、野猪王 |
| `shadow.png` | `character/Shadow.png` | 角色脚下阴影 |
| `club_in_hand.png` | `weapon/club/in_hand.png` | 玩家近战木棍 |
| `floor_atlas.png` | `map/tileset_floor.png` | 草地颜色与地面风格参考 |
| `village_atlas.png` | `map/tileset_village_abandoned.png` | 村屋与树木来源图集 |
| `hut_weapon.png` | `village_atlas.png` 的裁切 | 村落武器铺 |
| `hut_synthesis.png` | `village_atlas.png` 的裁切 | 村落合成铺 |
| `tree_round.png`、`tree_tall.png` | `village_atlas.png` 的裁切 | 村落外围林木 |
| `arena_ground.png`、`village_ground.png` | 以原素材调色的组合贴图 | 战斗草地、村落草地与土路 |

这些资源只用于当前原型展示，画风和尺寸还没有经过最终美术定稿。保留本说明以便之后替换或核对来源。
